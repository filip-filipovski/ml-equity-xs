\section{Reproducibility}\label{app:repro}

Every table and figure in this paper is generated by two scripts (\path{paper/build_tables.py}, \path{build_figures.py}) from stored result files; no number in a table is typed by hand, and the numbers quoted in the text are macros written by the same script. Sources: the 55-cell grid and its cost ladder (\path{p12c_eval.json}), the cost-ladder inversion (\path{p12c_what_it_takes.json}), Sharpe standard errors (\path{p12c_precision.json}), the expected maximum of $N$ and the zero-cost benchmarks (\path{p12_stage4.json}), the out-of-window and hold-out IC reads (\path{p9_e6.json}, \path{p9_b_wfa.json}, \path{p9_b_fullhistory.json}), the power calculation (\path{p9_b_forward_power.json}), all under \path{results/}; and the graph programme's generated results file (\path{results/gnn/RESULTS.md}, with \path{STATE.json}). A self-test reproduces the stored cost ladder from eq.~\eqref{eq:ladder} for all 55 cells and reproduces the stored expected maximum of 294 null Sharpe ratios by simulation.

The graph programme's hyperparameters are one set, hashed (\path{872821b168bcbcc3}) and registered before any graph result was read; the trainer and the book evaluator refuse unregistered hashes. Its prediction files carry the panel fingerprint, the hyperparameter hash and the code hash, and must reproduce the exact row sets of the portfolio grid (1{,}347{,}743 / 318{,}475 / 103{,}945 rows). $\numPthirteenRefits$ refits were trained. Pre-registration documents, an independent design review with four closure passes, and the results file are in \path{docs/} and \path{results/gnn/}; the 349-cell portfolio programme's pre-declaration, result and independent red team are in \path{docs/} and \path{results/}.

Zone attestation. Training-zone rows only (formation months 2009-01 to 2022-12, maximum formation date 2022-12-20 weekly); the 2023 walk-forward rows were scored once under a frozen rule (an earlier script loaded and masked them without scoring); no price or return from the sealed zone from 2024-07-01 has been read by any script in this programme (the survivorship diagnostic's 2026-vintage filing-status table reaches into it for two 2023 formations, with no returns). The check window 2019--2022 was used as a check four times, which Section~\ref{sec:valid} counts.
