\section{Validation geometry}\label{sec:valid}

\paragraph{Expanding refits with an embargo.}
Let $\mathit{mi}=12\cdot\mathrm{year}+\mathrm{month}-1$ index the \emph{entry} month of a label. For each out-of-sample year $Y\in\{2009,\dots,2022\}$ a new model is fitted on data strictly before $Y$, with embargo $e=1$ month and a 12-month validation slice:
\begin{equation}\label{eq:split}
\text{test}=[12Y,\,12Y{+}11],\qquad \omega=12Y-1-e,\qquad \text{val}=[\omega-11,\,\omega],\qquad \text{fit}=[m_0,\ \omega-13],
\end{equation}
$m_0$ = February 2004, with a one-month gap between fit and validation. The condition that has to hold is one on daily returns rather than on month labels. With $\mathrm{entry}(l)$ the close at which a label's holding window starts (row $t{+}1$) and $\mathrm{exit}(l)$ the close at which it ends (row $u{+}1$),
\begin{equation}\label{eq:embargo}
\max_{l\in\text{fit}\cup\text{val}}\mathrm{exit}(l)\ \le\ \min_{l\in\text{test}}\mathrm{entry}(l),\qquad
\max_{l\in\text{fit}}\mathrm{exit}(l)\ \le\ \min_{l\in\text{val}}\mathrm{entry}(l),
\end{equation}
so no two labels on opposite sides of a boundary share a daily return. The same $e=1$ and validation slice are used at every horizon; eq.~\eqref{eq:embargo} then holds by arithmetic on entry and exit rows (strictly at the weekly and monthly horizons, with equality of exit and entry closes at the quarterly one). This is a property of the construction, and only the earlier window-grid study's splitter asserts it in code. Refits retrain from scratch with seed = base seed + first test month index.

\paragraph{Graph-network masks.}
The graph experiments use no validation slice: test rows have $12Y\le\mathit{mi}\le12Y{+}11$; training rows have $\mathit{mi}\le12Y-2$ and $\mathrm{exit\_date}\le$ the earliest test formation date. They train through November of $Y{-}1$ (the booster's fit slice ends in October of $Y{-}2$); both respect eq.~\eqref{eq:embargo}.

\paragraph{What ``no selection'' means.}
The headline booster's depth, learning rate, rounds and subsampling were fixed before the out-of-window reads, but the configuration itself was chosen as the best of three model classes on development, with a development IC of $+0.031$ on the original panel as the best of five seeds ($+0.029$ averaged) and $+0.023$ on the corrected panel of Table~\ref{tab:ic_windows} (cause not isolated). Fixing the hyperparameters matters, because with per-refit selection over a 144-cell grid on the 12-month validation IC the same class reads $+0.014$, about ridge's $+0.013$, since the validation IC has a standard error of about 0.024 while the selected grid point's margin over the next best is 0.000 to 0.005. The graph networks' single hyperparameter set was hashed and registered before any graph result was read; the code refuses unregistered hashes.

\paragraph{Trial counting.}
The portfolio programme has $N=349$ pre-declared cells: 294 in a first programme (234 monthly cells with a 2019 to 2022 check window and 60 weekly cells on panels ending 2018) and a 55-cell grid on panels rebuilt through 2022, first run on development only on the older panels and counted once. Each graph-network prediction set evaluated adds 55, so the graph programme counts $N=349+55k$. Section~\ref{sec:infer} turns $N$ into an expected maximum of null Sharpe ratios and a deflated Sharpe ratio \citep{baileylopez2014}. The check window had been read three times before the graph experiments (the out-of-window replication, an earlier graph-feature study, the 349-cell programme), so every pass on it is a pass on a reused window.
