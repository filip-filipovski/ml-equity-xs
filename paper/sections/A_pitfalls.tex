\section{Pitfalls that changed numbers}\label{app:pitfalls}

Each item altered a reported statistic before it was found, and its fix is now part of the protocol.
\begin{enumerate}
\item \textbf{Constant booster and ties.} Tiny pairwise hessians with \texttt{min\_child\_weight} 500 forbade every split; a stable sort ranked the constant alphabetically (IC $\pm0.02$). The fixes are \texttt{min\_child\_weight} 1, a non-degeneracy assertion, a tie-safe average-rank IC and seeded tie-breaks.
\item \textbf{Validation-IC noise.} Standard error 0.024 on a 12-month slice against grid margins of 0.000 to 0.005; early stopping halted at about five trees. The fix is a fixed number of rounds with no per-refit selection.
\item \textbf{Rank target not market-neutral.} Correlation 0.75 with Mkt-RF; a validation year in a falling market selects a low-beta book. The fix is an ex-ante beta per year, eq.~\eqref{eq:neutral}.
\item \textbf{Cost-confounded permutation null.} Random decile books turn over 1.6 times more, so beating them on net Sharpe ratio measured lower turnover (net $p=0.002$, gross $p=0.42$). The fix is to evaluate the null on the gross statistic.
\item \textbf{Survivorship-loaded features.} Reversal and idiosyncratic volatility dominate. The fix is an ablation diagnostic, while a delisting-inclusive panel remains open.
\item \textbf{Price levels wrong by future splits.} The \$5 filter and the five price-level characteristics are wrong by later splits (Section~\ref{sec:limits}), and the fix is a variant without them.
\item \textbf{Forward-looking event flags.} Two earnings-calendar flags used later 8-K filings. The fix is a clean point-in-time event mask.
\item \textbf{Cache key and annualisation.} A cache keyed without the split returned another split's predictions; weekly series annualised with $\sqrt{12}$ mis-ranked cells in a deflated Sharpe ratio. The fix puts split and horizon in the key and uses per-horizon periods per year (50.4 / 12 / 4; books use 52, rescaled by $\sqrt{50.4/52}$ in selection).
\item \textbf{Validation-selected ``no signal''.} Six model classes read rank IC at most $+0.017$ only when validation-selected and early-stopped, so the selector rather than the models caused the result.
\end{enumerate}
